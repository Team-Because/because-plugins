# Industry kit · Real estate (residential, commercial, plotting)

Client-neutral. Built 12-10-2026 from the studio's first real estate film (a 30 s commercial-tower launch ad, 3 formats).

## What the viewer must get
Where it is, what it is, the one number that makes it different, how to enquire. Real estate ads are bought on trust:
real renders, real numbers from the project page, the developer's name on the lockup.

## Visuals used so far (options, not a template: the reference and concept decide)
- The developer's own renders, never generated buildings. Move them in code: slow push, tilt up a facade, parallax.
- A build reveal: the tower assembles floor by floor on the real render (mask per floor band).
- A height or count proof: counter from 0 to the page's number, landing on a downbeat.
- One address or amenity per beat, each with its own transition (2-2.5 s each).
- The site's own hero video, if it has one, as the hook background.
- End card: project wordmark + developer wordmark, CTA pill, phone, QR to the project page, RERA line.

## Copy patterns seen so far
- Teaser then reveal (campaign level); hoardings often run alongside.
- Rhetorical contrast: an everyday frustration, a short reaction, the feature as a deliberate design choice.
- Local-language wordplay for campaigns where the client uses it (check the client CLAUDE.md for the channel's tone).

## Compliance (check every time)
- RERA registration number of the project + the state RERA portal address on every project ad. Studio practice from
  the first film's brief; legal source (RERA Act 2016, s.11(2)) still to be confirmed before calling it the law.
- Possession dates, areas, heights: only from the project page, quoted in the client's products/<slug>/facts.md.
  If the page contradicts itself, ask.
- No prices, discounts or returns unless the brief gives them with their conditions.
- Licensed fonts only (site trial fonts are not licensed for delivery).

## Formats
OTT/TV 16:9 master with TV-readable type, plus 9:16 Reel and 1:1 from the same timeline.
