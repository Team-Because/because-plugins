# Occasion kit · Republic Day

Client-neutral. Built 12-10-2026. A brief accelerator, not a template: the reference and the picked concept decide the shots.

## The occasion
26 January 1950, when the Constitution took effect. The Kartavya Path parade, state tableaux, the Beating Retreat on 29 January.

## The cliche to avoid
The same tricolour sale as Independence Day, and the same flag-law problem (Flag Code of India 2002, 2.1(i): https://www.mha.gov.in/sites/default/files/flagcodeofindia_070214.pdf). The Constitution gives a better idea: rights, a citizen's voice, building something that lasts.

## Colours (festival accents; the client's brand colours always lead)
Same as Independence Day: saffron #FF9933, white, green #138808, navy #000080 as separate accents, never as a flag.

## Motifs
The parade march, the Constitution's preamble type, tableaux, the fly-past. No flag, no emblem, no Ashoka Chakra.

## Date rule
Fixed: 26-01 every year. 2027: 26-01-2027 (Tuesday).

## Lead time (studio default, not data)
Brief 3 weeks out; it falls in the January sale window, so retail clients often run a long weekend sale.

## Sectors that use it
Retail sales, education (civic values), B2B greetings.
