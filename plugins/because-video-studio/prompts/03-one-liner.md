# Step 03 · One-liner showreel prompts

Source: @0xMovez course, step 03 (https://x.com/0xMovez/article/2104216919033192746).
Use these to test the setup. A one-liner tests the engine, never the idea, because it does not contain one.

## The original (run it at xhigh or max effort)

```
make a dynamic 15-second motion graphics video that shows what an incredible motion designer
you are, like it's your showreel for a résumé. go all out.
```

Why it works:
- "showreel for a résumé" names a genre with known rules: fast cuts, a new technique every shot, best work first.
- "what an incredible motion designer you are" makes the model the subject, so there is no product content to get wrong.
- "15-second" is short enough to finish in one pass, long enough for 6 to 8 shots.
- "go all out" works as an effort multiplier on top of xhigh or max.

Weakness: "brief contagion". Hundreds of people ran the same line, so the reels rhyme with each other.

## Variants (fill the brackets, run from a fresh session in motion-studio/)

Longer, with a sound bar (pattern from @kloss_xyz):
```
make a dynamic 16:9, 60-second motion graphics showreel that shows your real creative limits.
S-tier sound design, no generic synth pads. Compose an original piano score and sync every
cut to it. Export 1080p MP4.
```

Anti-slop guardrail (pattern from @1littlecoder):
```
make a dynamic 10-second motion graphics video that introduces who you are as Opus 5.5.
Avoid frames and text in the corners, the usual giveaways of AI-made video.
```

Story instead of techniques (pattern from @sonnylazuardi):
```
use your showreel energy, but tell a story: the history of [TOPIC] from [START] to today,
surprise me with the storyboard. 45 seconds, vertical 9:16.
```

Agency persona:
```
make a 30-second showreel as if you were a niche branding studio for startup founders.
Create every graphic from scratch. One accent color. Every shot is a different technique.
```
